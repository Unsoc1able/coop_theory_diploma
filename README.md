# Кооперативная модель R&D — дашборд

Репозиторий содержит интерактивный дашборд на [Plotly Dash](https://dash.plotly.com/),
который визуализирует параметры кооперативной модели исследований и разработок,
а также заготовки под расширение проекта.

## Структура проекта

```
app/
├── __init__.py          # фабрика Dash-приложения и базовый layout
├── app.py               # entry-point для запуска локального сервера
├── assets/              # глобальные стили Dash
├── data.py              # исходные данные и пресеты параметров
├── logic.py             # бизнес-логика и расчёты модели
└── pages/               # многостраничный интерфейс
    ├── __init__.py
    ├── model.py         # основная страница: параметры, портфели, графики
    └── coop.py          # страница кооперации и расчёта Шепли

data/
└── parsers/             # заготовки для парсеров внешних источников
    ├── __init__.py
    └── base.py          # базовый класс и модель результата парсинга

tests/
└── test_logic.py        # unit-тесты ключевых расчётов
```

Дополнительно в корне сохранена исходная HTML-версия интерфейса (`cooperative_rnd_model_interactive.html`) для сравнения.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.app
```

После запуска сервер доступен на `http://127.0.0.1:8050/`.

## Тесты

pytest
